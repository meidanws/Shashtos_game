# מוזיקת הרקע

שימו כאן את קובץ השיר בשם **`theme`** — הסיומת לפי מה שיש לכם:

| סיומת  | הערות                                                               |
| ------ | ------------------------------------------------------------------- |
| `.mp3` | **מומלץ** — עובד בכל דפדפן. 128–192 kbps מספיק בהחלט (שיר של 2 דקות ≈ 2–3 MB) |
| `.m4a` | AAC. עובד בכל הדפדפנים המודרניים                                     |
| `.ogg` | Vorbis. לא עובד בספארי                                               |
| `.opus`| לא עובד בספארי                                                       |
| `.webm`| לא עובד בספארי                                                       |
| `.wav` | ללא דחיסה — איכות מושלמת אבל כבד מאוד (2 דקות ≈ 20 MB)                |

המשחק מחפש אותם בסדר הזה ולוקח את הראשון שהוא מוצא, למשל:

```
public/audio/theme.mp3
```

זה הכול. אין מה לייבא ואין מה לעדכן בקוד — הקובץ נטען בזמן אמת, וכל עוד הוא
לא קיים פשוט אין מוזיקה והכפתור בהגדרות מראה ״אין קובץ מוזיקה״.

## הלופ

השיר מתנגן בלופ אינסופי. מקודדים כמו MP3 ו‑AAC מוסיפים שבריר שנייה של שקט
בהתחלה ובסוף, ולכן המשחק מאתר לבד את הדגימה הראשונה והאחרונה שנשמעות בהן
ומסובב את הלופ ביניהן — כך שאין פאוזה בין סוף השיר לתחילתו. אין צורך לחתוך
את הקובץ מראש.

כדי שהמעבר יישמע חלק באמת, כדאי שהשיר ייגמר בערך איפה שהוא מתחיל (אותו
אקורד/ביט), בלי fade out בסוף.
